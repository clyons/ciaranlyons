## Context and Orientation

The site is an Astro static site. TIL entries live under `content/til/<topic>/<slug>.md` and are loaded by `src/lib/content.ts`.

Relevant files:

- `content/til/`: Source directory for TIL Markdown and colocated assets.
- `src/lib/content.ts`: Loads TIL Markdown, derives date-folder URLs, and returns `TilEntry` objects.
- `src/pages/til/[topic]/[year]/[month]/[day]/[slug].astro`: Renders individual TIL pages.
- `src/pages/til/index.astro`: Lists and searches TIL entries.
